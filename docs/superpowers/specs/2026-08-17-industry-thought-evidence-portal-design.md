# 行业思考与项目证据圆弧入口设计

## 目标

重构 `/notes` 的内容关系：行业思考作为主叙事，项目经历作为可按需打开的证据空间。两者保持明确视觉反差，不在同一篇文章中连续混排。

## 信息架构

### 文章空间

- 浅色纸张背景，负责长篇行业观点与推理过程。
- 第一篇主题为“数据不等于价值”。
- 正文围绕四个递进层次展开：数据可见、数据可信、数据可解释、数据进入行动。
- 文中只出现一个轻量证据入口：“查看这项判断从何而来”。
- 文章不在正文段落中重复项目过程、项目角色和结果指标。

### 项目证据空间

- 由文章入口触发，当前页面内展开，不创建新的浏览器页面。
- 深色背景、网格结构和橙色强调线，与文章空间形成明确反差。
- 内容固定为四组：现实矛盾、我的判断、推动改变、结果验证。
- 代表项目为“DMS 全国渠道分销透明化治理”。
- 事实数据可展示“600+ 重点经销商上线”和“上传率由 70% 提升至 90%”。
- 项目空间用于证明行业判断来源，不替代项目详情页，也不展开完整复盘。

## 转场与交互

### 打开

1. 入口文字变为橙色圆点。
2. 从圆点位置沿圆弧向外展开。
3. 浅色文章空间被深色证据空间覆盖。
4. 证据标题、四组内容和结果指标依次进入。

总时长目标约 0.8 秒；动画只使用 transform、opacity、clip-path 等可合成属性，避免滚动卡顿。

### 关闭

- 点击“收拢证据空间”返回。
- 按 Escape 返回。
- 关闭后恢复文章原滚动位置，并将焦点返回入口。
- 用户开启减少动态效果时，取消圆弧动画，改为即时切换与淡入。

## 响应式策略

- 桌面端使用完整圆弧展开和双空间布局。
- 移动端保留圆点扩张与颜色切换，证据内容改为单列。
- 移动端不依赖大面积固定高度或横向溢出。

## 边界

- 本次只处理第一篇行业思考与其对应的 DMS 项目证据入口。
- 不新增案例，不重写其他行业思考，不进入 AI 内容。
- 具体项目详情仍由现有案例页面承载。
- 不引入新的动画库；优先复用现有项目动画能力。

## 验收标准

- `/notes` 首屏仍以行业思考为主，项目内容不会直接抢占正文视觉层级。
- 点击证据入口后，能看到明确的圆弧空间切换，而非普通下拉或页面拉伸。
- 证据空间能完整表达矛盾、判断、行动和结果四层关系。
- 打开、关闭、Escape、焦点恢复和减少动态效果均可用。
- 桌面端与移动端无横向溢出；页面返回 HTTP 200。
- 现有测试与 lint 保持通过。
