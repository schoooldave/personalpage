# 全站中英日三语设计规格

## 1. 目标

在不改变现有页面设计、内容层级和动效的前提下，为整个个人网站提供中文、英文和日文三种完整语言版本。

- 默认语言：简体中文
- 可选语言：英文、日文
- 中文路径：`/`
- 英文路径：`/en/`
- 日文路径：`/ja/`

## 2. 范围

三语需覆盖全部正式页面和全部用户可见文本：

1. 个人世界首页及工作世界切换状态
2. 关于我
3. 全国分销数据治理项目
4. SFA 销售执行产品线实践
5. 《数据不等于价值》
6. 《系统不等于业务闭环》
7. 《上线不等于持续使用》
8. 《从真实业务问题，走向下一代工作方式》
9. 导航、按钮、辅助说明、页面标题、描述与无障碍文本

简历 PDF 目前仍属于独立未完成项，本次不创建三语 PDF，但其入口文案需要三语化。

## 3. 路由与切换规则

中文继续使用现有无前缀路由，英文和日文使用语言前缀。

| 中文 | 英文 | 日文 |
| --- | --- | --- |
| `/` | `/en/` | `/ja/` |
| `/about` | `/en/about` | `/ja/about` |
| `/cases/dms` | `/en/cases/dms` | `/ja/cases/dms` |
| `/cases/sfa` | `/en/cases/sfa` | `/ja/cases/sfa` |
| `/notes` | `/en/notes` | `/ja/notes` |
| `/notes/system-process` | `/en/notes/system-process` | `/ja/notes/system-process` |
| `/notes/continuous-use` | `/en/notes/continuous-use` | `/ja/notes/continuous-use` |
| `/notes/ai-outlook` | `/en/notes/ai-outlook` | `/ja/notes/ai-outlook` |

语言切换器在所有页面保持可见，显示为 `中 / EN / 日`。切换时保留当前页面语义，不强制跳回首页。例如，在 `/cases/dms` 选择日文后进入 `/ja/cases/dms`。

直接访问 `/` 始终为中文，不根据浏览器语言自动跳转，确保“默认中文”的行为稳定可预期。

## 4. 内容架构

使用“共享页面结构 + 分语言内容库”，不复制三套页面组件。

- `zh-CN`：当前中文内容，作为事实源
- `en`：专业、自然的英文本地化内容
- `ja`：符合日文阅读习惯的本地化内容

页面组件只负责布局和交互，通过当前语言获取文案。项目数据、时间、指标和事实在三种语言中保持一致。

## 5. 翻译原则

1. 不使用运行时机器翻译，不调用外部翻译接口。
2. 不逐字直译，保留原文事实和个人语气，按英语和日语的表达习惯重写。
3. DMS、SFA、AI、FMCG、KPI 等通用缩写保留，首次出现时在需要处补充说明。
4. 项目结果、角色边界和时间线不因翻译而扩大或弱化。
5. 中文内容后续变更时，三语内容库中对应键必须同步更新。

## 6. 界面设计

- 语言切换器融入现有顶部导航，不新增悬浮弹窗。
- 当前语言有清晰的选中状态，其他语言保持低强度。
- 切换不增加复杂动效，避免对当前页面的流畅度和资源占用造成影响。
- 英文和日文长度变化通过容器宽度、自动换行和小范围字号适配处理，不分别重做页面。
- 个人世界与工作世界的视觉区隔保持不变。

## 7. SEO 与可访问性

- 每个语言路径设置正确的 `lang`、页面标题和描述。
- 中英日对应页之间输出 `hreflang` 关系。
- 语言切换使用真实链接，可用键盘访问，并为辅助技术提供明确标签。
- 中文无前缀页作为 `x-default`。

## 8. 容错与回退

- 非法语言前缀返回 404，不隐式猜测用户意图。
- 开发阶段如某个翻译键缺失，显式回退到中文，保证页面不空白；同时在检查中报告缺失键。
- 上线前三种语言必须通过内容完整性检查，正式页面不应依赖中文回退。

## 9. 验收标准

1. 八类正式页面均可通过中、英、日独立路径访问。
2. 任意页面切换语言后仍停留在同一内容页。
3. 导航、按钮、正文、辅助文本和元数据均使用当前语言。
4. 三语下页面无明显溢出、遮挡、错位或导航断行异常。
5. 原有个人页面、工作页面、项目页和文章页的布局与动效不被破坏。
6. 直接访问 `/` 默认显示中文。
7. 构建、类型检查、路由对应和翻译键完整性检查通过。

## 10. 不在本次范围

- 自动检测浏览器语言并强制跳转
- 在线机器翻译或翻译 API
- 内容管理后台
- 三语简历 PDF
- 因多语言而重新设计已确认页面
